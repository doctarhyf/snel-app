# SNEL RDC — Customer app prototype

Mobile-first MVP prototype (FR). No dependencies, no install step.

    npm start

Then open http://localhost:5173 (use browser device mode, or open the Network URL on your phone).
Change port: `PORT=3000 npm start` (Windows PowerShell: `$env:PORT=3000; npm start`).

Requires Node.js 18+. The whole UI is in `public/index.html`.

## Official logo
Drop your official logo file at `public/logo.png` (transparent PNG, ~40px tall works best).
The app shows it automatically; until then a neutral placeholder mark is used.
